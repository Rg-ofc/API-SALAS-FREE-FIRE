Documentação da API Pública & Integrações

Guia de referência técnica do criador de salas de Free Fire. Integre e chame em bots, painéis ou sistemas via requisições HTTP REST.

Informações Gerais & Autenticação

Todas as requisições devem incluir o cabeçalho Content-Type: application/json.

Para rotas do Cliente, envie o parâmetro oauth_key. Para rotas administrativas, envie o token no cabeçalho x-admin-token ou como Authorization: Bearer <token>.

URL Base da API: https://neonsalas.store

1. Utilitários & Conexão

GET /ping GET /health

2. Licenciamento & Saldos

POST /api/verificar-key POST /api/v1/me POST /api/v1/verify/me

3. Gerenciamento de Salas

4. Faturamento & Cobranças PIX

GET /api/v1/pagamento/config POST /api/v1/criar-pagamento POST /api/v1/pagamento/verificar POST /api/v1/pagamento/comprar-com-saldo

5. Integrações do Bot (Telegram)

POST /api/v1/telegram/verificar-permissao POST /api/v1/telegram/obter-keys-usuario POST /api/v1/telegram/usar-key GET /api/v1/telegram/obter-config POST /api/v1/telegram/atualizar-auto-start POST /api/v1/telegram/registrar-key POST /api/v1/telegram/remover-key POST /api/v1/telegram/listar-keys

POST /api/v1/create:room
Criar Nova Sala (Free Fire)

Inicia a criação automatizada de uma sala personalizada pelo bot do jogo.

POST https://neonsalas.store/api/v1/create:room

Parâmetros da Rota

Campo Tipo Exigência Descrição
oauth_key string Obrigatório Sua chave de licença
modo int Opcional 1=Solo, 2=Duo, 3=Squad, 4=Contra Squad
senha string Opcional Senha de acesso (padrão: 00)
nome string Opcional Nome personalizado do lobby
room_image bool Opcional Habilitar tirar foto do lobby (true/false)
auto_start_min int Opcional Minutos para início automático (1 a 15)
Exemplo Request (cURL) 
curl -X POST https://neonsalas.store/api/v1/create:room \
  -H "Content-Type: application/json" \
  -d '{
  "oauth_key": "FFSL-X",
  "modo": 3,
  "senha": "88",
  "nome": "Neon Salas | Camp",
  "room_image": true,
  "auto_start_min": 5
}'
Testar Parâmetros
Response Exemplo 
{
  "status": "OK",
  "sshash": "S-592815",
  "room_id": "98725102",
  "senha": "88",
  "msg": "Lobby em criacao..."
}
